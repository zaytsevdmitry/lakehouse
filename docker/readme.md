# Назначение
Данные образы предназначены в первую очередь для ознакомления с функционалом. Для продуктовой среды понадобится собственная сборка образов под вашу инфраструктуру.
Данные образы могут служить примером, либо быть использованы как есть если это приемлемо в вашей инфраструктуре.
